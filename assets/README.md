# Banner artwork

The starfield is recorded from the unmodified [Galaxy component by React Bits](https://reactbits.dev/backgrounds/galaxy), using source revision [3a1c7f2](https://github.com/DavidHDev/react-bits/tree/3a1c7f2f9f94ed833934ab5c2635760b9e644583). Copyright © 2026 David Haz. See the accompanying [license](./react-bits-LICENSE.md).

The capture runs the component's default dark settings with mouse interaction disabled. The foreground uses the demo's Geist typeface with a heading enlarged by 30%, with the text changed to PerfectPan and a subdued silver color. Frames are converted to neutral grayscale and joined with a short crossfade for looping.

- `profile-stars.gif`: 1320 × 420, 80 frames, 20 fps, 4-second loop, displayed at up to 880 pixels wide.
- `profile-stars.png`: static fallback for visitors who prefer reduced motion.

The [complete renderer source and reproduction guide](../tools/banner/README.md) are stored in this repository.
